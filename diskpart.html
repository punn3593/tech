สื่อการเรียนรู้: คืนชีพดิสก์ระดับเทพด้วย Diskpart

เรียนรู้โครงสร้างการจัดเก็บข้อมูล เทคนิคเคลียร์พาร์ทิชันตกค้าง และทดลองใช้ Command Line จริง

1. ทำไมต้องใช้ Diskpart แทน Disk Management?

Disk Management (GUI)

  • เหมาะกับการใช้งานทั่วไป ผ่านหน้าต่างกราฟิกคลิกง่าย
  • ข้อจำกัดหลัก: ไม่สามารถลบพาร์ทิชันระบบบางประเภทได้ เช่น EFI System, OEM Recovery หรือพาร์ทิชันข้ามระบบอย่าง Linux (EXT4)
  • ไม่สามารถข้ามการล็อกความปลอดภัยของ Windows ได้

Diskpart (Command Line)

  • เครื่องมือระดับล่าง สั่งงานตรงถึงดิสก์คอนโทรลเลอร์
  • คำสั่งเด็ด (clean): สั่งเขียนทับลบโครงสร้าง MBR/GPT และตารางพาร์ทิชันทิ้ง 100% ในทันที
  • แก้ปัญหาความจุ SSD หาย, ไดรฟ์ติด Read-Only หรือพาร์ทิชันขยะได้อย่างเด็ดขาด

2. ความรู้เสริม: MBR vs GPT & NTFS vs FAT32

รูปแบบตารางดิสก์ (Partition Table)

• MBR (Master Boot Record): รูปแบบเก่า รองรับความจุสูงสุด 2 TB และสร้าง Primary Partition ได้ไม่เกิน 4 พาร์ทิชัน
• GPT (GUID Partition Table): รูปแบบใหม่ รองรับความจุระดับ TB/PB ไม่จำกัดพาร์ทิชัน และรองรับระบบบูต UEFI

ระบบไฟล์ (File System)

• NTFS: มาตรฐานของ Windows รองรับไฟล์ขนาดใหญ่เกิน 4GB และมีระบบความปลอดภัยสูง
• FAT32 / exFAT: เหมาะกับแฟลชไดรฟ์/อุปกรณ์พกพา รองรับหลายระบบปฏิบัติการ (Windows, Mac, Android)

3. ลำดับคำสั่งการกู้คืนและล้างดิสก์

  • 1 diskpart - เปิดโปรแกรมจัดการดิสก์ผ่าน Command Prompt
  • 2 list disk - ตรวจสอบหมายเลขดิสก์ทั้งหมดที่เชื่อมต่อในเครื่อง
  • 3 select disk X - เลือกดิสก์เป้าหมายที่ต้องการจัดการ (ตรวจสอบให้แน่ใจ!)
  • 4 clean - ล้างตารางพาร์ทิชัน ข้อมูล และความผิดพลาดทั้งหมดทิ้ง
  • 5 convert gpt - แปลงโครงสร้างดิสก์ให้เป็นมาตรฐาน GPT สมัยใหม่
  • 6 create partition primary - สร้างพาร์ทิชันหลักเต็มพื้นที่ดิสก์
  • 7 format fs=ntfs quick - ฟอร์แมตรูปแบบ NTFS แบบรวดเร็ว
  • 8 assign - กำหนดไดรฟ์ (เช่น Drive D:, E:) เพื่อเริ่มใช้งานบน Windows

4. ห้องทดลอง: ลองพิมพ์คำสั่งจริงพร้อมดูผลลัพธ์ Visual!
